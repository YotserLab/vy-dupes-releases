# VYDupes — Releases

Binários oficiais do **VYDupes**, scanner de arquivos duplicados de alta
performance com interface web (backend Go + SPA embutida em um único
binário).

Baixe a versão mais recente em
[**Releases**](https://github.com/YotserLab/vy-dupes-releases/releases),
rode o binário e abra `http://localhost:45400`.

| Plataforma | Arquivo |
|---|---|
| Linux x86_64 | `vydupes_*_linux_amd64` |
| Linux ARM64 | `vydupes_*_linux_arm64` |
| macOS Intel | `vydupes_*_darwin_amd64` |
| macOS Apple Silicon | `vydupes_*_darwin_arm64` |
| Windows x86_64 | `vydupes_*_windows_amd64.exe` |

> Ferramenta local, sem autenticação — não exponha a porta publicamente.
